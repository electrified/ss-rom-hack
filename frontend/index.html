SENSIBLE SOCCER

Sensible Soccer ROM Editor for Mega Drive / Genesis

Edit teams, players and kits in your browser. Your ROM files and edits stay on your device; no installation is needed.

The editor requires JavaScript. If it does not load, enable JavaScript or reload the page. You can read the instructions and supported versions below without it.

Supported versions

This editor supports the International and Original/European editions of Sensible Soccer for the Sega Mega Drive. The console is also known as the Sega Genesis; this does not mean every regional ROM release has been tested. Open a supported ROM in .md or .bin format. Amiga, PC and other console versions are not supported.

You supply your own ROM file. This site does not provide game downloads. Keep an untouched copy of your original ROM so you can return to it later.

What you can edit

Update national, club and custom teams, including team names, countries, coaches, formations, skills and flags. Change player names, positions, roles, shirt numbers, head types and star-player flags. Choose kit colours and styles to give each team its own appearance.

You can also export team data as JSON and import it again later. Imports are validated before replacing the current document, and invalid imports leave your current edits intact.

How to use the editor

  1. Choose Open ROM file above, or drag a supported file into the upload area.
  2. Select a category and team, then edit its players, team details and kits.
  3. Resolve any validation errors and check the displayed team-data byte budget.
  4. Export JSON to save your team data, or choose Download Modified ROM to save a playable ROM with your changes.

The download is a new file; the editor does not overwrite your original. The ROM checksum is updated when the modified file is generated.

Common questions

Are my ROM files uploaded?

No. ROM decoding, editing and downloading happen locally in your browser. Google Analytics measures visits, but ROM contents and team edits are not sent to it.

How do I keep my changes?

Download the modified ROM or export JSON before closing or refreshing the page. Unsaved edits are held in memory. Opening another ROM or choosing Start Over begins a new document.

Why can’t I download my edited ROM?

Downloads are disabled while validation errors remain. Names and other text must fit the supported character set and length limits. Longer names can also exceed the ROM’s total team-data capacity, even when each name is individually valid. Shorten text or correct the highlighted fields, then try again.
